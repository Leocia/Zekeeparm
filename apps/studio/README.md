# Zekeeparm Studio 0.1.0

面向新手的本机积木编程工作台。浏览器界面与 Python 控制服务运行在同一台电脑，机械臂通过 USB 串口连接这台电脑。核心控制不需要 ROS、MoveIt、云服务或模型 API Key。

这是可运行的第一版。Linux 模拟流程已经验证，Windows 安装包构建和 Windows 真机运行尚未验证；仓库不包含已经验证的 Windows `.exe`。

## 当前能力

- 中文 Blockly：系统与模式、关节与示教、运动学计算、变量、数学、逻辑、数据、Python、函数、夹爪、流程十一个分类，共 41 种积木（含程序入口）。
- 对照功能表新增控制器启停、安全回零、轨迹曲线、单关节相对微调、程序内记录示教点、FK、IK、可达性、轨迹质量统计、模型信息。
- 支持值积木连接、关节角列表、计算结果驱动关节运动、如果/否则，以及结果日志。
- 原始 CAD/URDF 三维显示、视角拖动和缩放、全屏预览、程序预览和当前积木高亮。全屏后底部可调六轴目标角，并可直接移动到目标或运行积木程序；右侧实时角度窗可拖动，也可聚焦后用方向键微调位置。
- 三维窗口在运行前跟随关节滑条、角度输入和 IK 结果显示目标姿态，不发送运动命令；开始运行后切换为机械臂实时姿态。运行结束后继续显示实际姿态，拖动滑条时切回目标姿态。滑条旁保留角度数值，预览下方显示 J1–J6 当前角度。
- 放大的积木分类与独立缩放的选择栏；桌面优先展示编程区，1100px 及以下预览和设备面板移至下方。
- 模拟设备、运行进度、取消、错误与运行日志。日志位于右侧面板底部，默认收起，展开后以深色背景和白色文字显示；点击“清空”删除当前运行日志，之后的新记录继续显示。
- 使用 SDK 的 Pinocchio 正逆运动学；TCP 为 `official_tcp`，坐标参考 `base_link`。
- 基于 Pinocchio/Coal 的机械臂自碰撞与固定工作台碰撞检查，复用 SRDF 自碰撞排除列表；目标预览会将碰撞连杆标红，碰撞路径会阻止执行。环境模型目前仅包含项目标定的固定工作台。
- 关节目标与实时角度显示两位小数；实时状态以 30 Hz 为目标刷新，上一请求未完成时跳过新请求，实际频率受设备反馈和电脑性能影响。桌面布局可拖动分隔条调整右侧面板宽度，宽度会保存在浏览器。
- 本机项目保存/打开、JSON 导入/导出、浏览器草稿恢复。
- SDK 真机适配入口，复用 `HardwareManager` 的关节映射、硬件参数、使能、夹爪和停止保持逻辑。

界面中的角度为度、位置为 mm；后端与项目关节数据为 rad，位姿接口为 m/rad。夹爪最大开口沿用 `70 × 1.35 / 1.45 = 65.1724 mm`。关节轨迹默认保持原有同步三次插值，可用积木切换最小冲击、梯形或线性曲线；按 `0.30 rad/s` 峰值速度延长运动时长。这不是末端直线运动。安全回零固定使用最小冲击曲线和硬件配置中的 `safe_home.positions`，可设置更低角速度、到位阈值及到位等待超时。

## 新增积木使用

- **系统与模式**：启动并使能、安全回零并保持、失能电机、控制模式；单独回零与轨迹参数。结束动作回零后继续保持力矩。需要释放力矩时，先可靠支撑机械臂，再点击设备面板独立的“失能”按钮，或执行“失能电机”积木；真机操作会先要求确认。失能不会自动回零，再次运动前须启动并使能。“安全回零并保持”动作不改变夹爪目标开口。
- **关节与示教**：J1–J6 相对角度微调自动限位；记录当前六轴关节角和位姿，示教点加入右侧列表，可后续移动、保存和导出。同名点拒绝覆盖；循环记录时需使用不同名称。下拉列表也提供程序内声明的示教点，后端要求该点在使用前已记录。
- **运动学计算**：FK 接收关节角列表，可返回位置、3×3 旋转矩阵、4×4 变换矩阵或完整位姿，允许指定模型中的坐标系。默认 `official_tcp` 沿用当前机器人的 TCP，不使用参考截图中其他机器人的 `gripper_end`。未连接关节角时使用当前位置。
- **IK / 可达性**：输入 XYZ（mm）和 RPY（°），随机重试为 0–8 次；IK 返回六轴角度列表（rad），可连接到“运动到关节角”。可达性布尔积木连接“如果”，分支支持那么/否则。可达只表示 IK 在关节限位内收敛，运动路径仍需碰撞检查。
- **预检轨迹质量**：目标关节角、持续时间、曲线、采样周期和加速占比生成独立笛卡尔测地线轨迹，输出 `success_rate`、`max_ik_error`、`avg_ik_error`、`total_points` 等统计。它不会发送运动，也不表示当前关节插值动作的硬件跟踪成功率。最多 501 个采样点，整段程序另有限制计算量。
- **模型信息**：输出自由度、关节名称、限位（rad）、默认 TCP 和全部坐标系。将值积木连接“显示结果到日志”，运行后在底部“运行日志”查看。

检查和预览不会使能、运动、修改示教点或切换硬件模式。执行前按程序初始姿态及前序目标计算所选条件分支和 IK 运动目标，并检查路径；执行时微调以实际当前位置为基准，记录示教点和显示结果读取实际反馈。条件与运动目标不会在执行途中自动重算；手动拖动后需停止并重新运行。预览使用后端检查后的相同分支、目标和速度曲线，不替代现场验证。

真机模式须匹配 `zekeep_hardware.yaml` 的 `control.arm_control_mode`；当前硬件管理器没有公开的动态模式切换接口，模式不匹配会在执行前拒绝。需显式失能、断开，修改并核验硬件配置后重连。模拟设备可切换两种模式。Studio 已移除重力补偿选项与调用，控制器启动直接复用 SDK 的反馈校验和使能，停止仍请求保持。旧项目打开时会移除控制器积木的旧 `GRAVITY` 字段，其他参数保留。

原有项目格式 `zekeeparm_studio_v1` 与原有积木类型保持兼容。新增积木项目不能由旧版编辑器打开。

## 常用逻辑积木

在原有 21 种积木上新增 18 种：

| 分类 | 积木与功能 |
| --- | --- |
| 变量 | 设置变量、读取变量、变量增加指定数值 |
| 数学 | 数字常量、加减乘除与取余、取整/绝对值/取负/角度弧度转换 |
| 逻辑 | 真/假常量、六种比较、并且/或者、取反 |
| 数据 | 文本常量、创建列表、取列表项、修改列表变量中的一项、长度、字典字段取值 |
| 函数 | 定义无参数动作函数、按名称调用函数 |

数字、列表或 IK 输出可以保存到变量，然后连接到“运动到关节角”等已有输入。列表序号从 **1** 开始，第 1 项对应 J1，第 6 项对应 J6。创建列表积木可修改“项数”（0–32），各项可以连接数字或其他值积木，保存/打开时保留项数和连接关系。列表赋值会复制内容，修改新列表不会改变原列表。

“如果”现在接受比较、逻辑运算、可达性、布尔变量等结果。逻辑输入必须是布尔值；并且/或者采用短路求值，只有需要时才计算右侧。数值运算不把真/假当作 1/0。`round` 沿用 Python 的就近取整、正好居中时取偶数规则。

字典字段直接填写字段名，例如：将“预检轨迹质量”保存为变量“统计”，再用“取字典字段”读取 `success_rate`，与 `0.99` 比较后连接“如果”。不存在的字段会报错，不会静默使用默认值。

函数定义独立放在工作区，不连接到程序入口；内部动作接在“执行”中。入口下放“调用函数”，填写相同名称。函数不支持参数、返回值或递归，共享本次程序的变量，可用于封装“取料”“放料”等动作。函数定义允许在调用之后放置；函数重名、缺失或递归会被检查拒绝。

例如，调整现有关节目标中的 J6：

1. 将“当前六轴关节角 rad”保存到变量“目标”。
2. 取“目标”的第 6 项，加上“角度转弧度 5”。
3. 将计算结果设为“目标”的第 6 项。
4. 将变量“目标”连接到“运动到关节角”。

变量每次检查、预览或运行时重新初始化，须先赋值再读取。变量赋值、列表修改、函数和条件在执行前根据初始姿态和前序目标计算，形成固定动作计划，再进行速度与碰撞检查；运行中不会根据传感器反馈重新计算变量或分支。日志显示各步骤对应的变量快照，检查和预览不改变设备状态。

最多 64 个变量、32 个函数；表达式嵌套最多 8 层，列表/字典值及文本均有限长。函数调用和循环共享原有展开步数与计算预算。除零、数值非有限或超过 ±10¹²、列表越界、类型错误、变量未赋值等错误会在发出运动命令前中止检查。普通逻辑积木通过固定运算白名单计算；Python 积木使用下述受限语法解释器，不执行系统 Python 脚本或 JavaScript。

## Python 计算块

从左侧“Python”分类拖入“Python 计算”，点击积木铅笔或编辑区上方的“Python”按钮打开多行编辑器。编辑器支持 Tab 缩进、Ctrl/⌘ + Enter 保存、Esc 取消；代码与结果变量名随项目保存、导入导出和草稿恢复。

代码可读取：

- `variables`：本次程序的变量字典，可通过 `variables["名称"]` 读取或更新。
- `joints`：该步骤对应的六轴关节角列表，单位 rad，是执行前计算的计划姿态。
- `result`：代码必须给此名称赋值，其值会写入积木指定的结果变量（默认“Python结果”）。

例如，只调整 J6：

```python
import math
result = list(joints)
result[5] += math.radians(5)
print("J6 目标", result[5])
```

将“变量 Python结果”连接到“运动到关节角”，运动仍经过原有六轴数据校验、关节限位、限速和自碰撞检查。Python 的列表下标从 **0** 开始，与普通“第几项”积木从 1 开始的序号不同。

支持的计算语法包括赋值、增量赋值、if/else、for、有条件列表推导式、列表/字典、下标/切片、算术与比较、布尔运算。可调用 `abs`、`round`、`min`、`max`、`sum`、`len`、`int`、`float`、`bool`、`str`、`list`、`sorted`、`range`、`enumerate`、`zip`、`print`，以及列表示例中的 `append` 和字典 `get`。

`math` 可直接使用或写 `import math`，提供 `pi/e/tau` 和三角函数、平方根、对数、取整、角度转换等固定函数。其他模块、系统命令、文件、网络和硬件对象不可用。此功能解释 Python 的一个受限计算子集，不是完整 Python 解释器；不支持自定义函数/类、while、异常处理、lambda、f-string、关键字调用参数等语法。

每个代码块最多 8192 字符、10000 个解释步骤或 2 秒，循环输入最多 256 项；打印最多 50 条、总计 4096 字符。结果沿用程序变量的数据大小、深度及有限数值限制。Python 块计入整段程序计算预算。运行前解释计算；检查与预览也会执行计算，但只操作临时数据，不产生文件、网络或硬件副作用。成功后才提交变量变化；失败会中止整段动作计划，不发送前序运动。

## 程序错误提示

编辑积木时不自动检查、不弹出错误提示。点击工具栏“检查程序”后，检查漏接值输入、游离积木、入口不唯一、变量未赋值、类型不匹配、除零、列表越界、函数缺失/递归、示教点缺失、运动参数或路径错误，以及 Python 语法和计算错误。“预览”和运行前仍保留相同检查，失败时中止并提示。

错误显示在编辑区上方，包含原因、修改建议和“定位积木”按钮；对应积木显示警告标记，Python 错误会尽可能保留行号。修改积木后旧提示清除，重新检查可确认修复。搭建时不会自动执行 Python 代码；代码计算和完整逻辑检查由检查、预览或运行触发。

这些检查验证数据、连接和可执行性，无法判断用户的动作意图是否正确；仍需预览并核对目标位置、顺序和现场环境。

## 本机启动

当前 Linux 工作区已有依赖，可直接运行：

```bash
cd /home/zekeep/Desktop/Zekeeparm/apps/studio
bash start.sh
```

打开 `http://127.0.0.1:8765`。启动只加载模型，不连接硬件、不使能电机。可先点击“预览”；要执行模拟任务，选择“模拟设备”，依次点击“连接”“使能”“运行”。

首次准备或迁移到其他电脑：

```bash
conda env create -f environment.yml
conda activate zekeep-studio
npm ci
python studio.py
```

Node.js/npm 仅用于准备 Blockly 静态资源；准备后离线运行不需要 Node.js。源码通过相对位置读取工作区模型和 SDK，迁移源码时应保留工作区目录结构。

Windows 源码启动可在上述环境准备完成后双击 `start_windows.cmd`，或者在已激活环境中执行 `python studio.py`。
首次安装成功后自动创建桌面快捷方式；已有环境可双击独立包根目录的 `4-create-desktop-shortcut.cmd` 补建。
快捷方式自动调用 `zekeep-studio` 环境并打开浏览器，控制窗口最小化，不用手动进入 Miniforge。
自定义安装位置未识别时，选择 Miniforge 安装目录中的 `Scripts\conda.exe` 或 `condabin\conda.bat`，快捷方式会记住路径。
软件目录或 Miniforge 目录移动后需重建快捷方式。独立 Windows ZIP 已带齐 Blockly 静态资源，可先运行 `setup_windows.cmd` 准备原生依赖，无需安装 Node.js。

## Windows 打包

在 Windows x64 开发电脑上安装 Miniforge，使用独立 ZIP 或保留所需目录结构，然后运行：

```powershell
cd <工作区>\apps\studio
.\build_windows.ps1
```

脚本准备独立 Conda 环境、Blockly 资源，运行后端测试，然后调用 PyInstaller 构建 `dist\ZekeeparmStudio\`，并运行产物的 `--self-test` 检查原生库、模型、SDK 导入和离线资源。完整目录包含 Python 运行时、原生依赖、模型和网页资源；不要只复制其中的 `.exe`。用户双击应用后自动打开本机网页。

额外安装 Inno Setup 6 并把 `ISCC.exe` 加入 PATH 后，可生成用户级安装包：

```powershell
.\build_windows.ps1 -Installer
```

输出为 `dist\ZekeeparmStudio-Setup.exe`，不安装开机系统服务。服务随应用启动，退出需结束后台控制服务。卸载应用不删除用户项目数据。Windows 包必须在无开发环境的目标电脑上验证 DLL 加载、USB 驱动和设备控制。PyInstaller 不能在 Linux 上直接产出可验证的 Windows 二进制。

## 真机入口

在设备面板选择“真机 · USB 串口”，填写 `COM3`（Windows）或 `/dev/ttyACM0`（Linux），显式连接并使能后运行。当前服务不扫描设备，也不会自动猜测串口。Windows COM 端口已接入 SDK 的达妙串口选择分支，但尚未进行 Windows 真机测试。

默认使用 `src/zekeep_bringup/config/zekeep_hardware.yaml`，保留现有关节方向、零点、控制增益和夹爪标定。不要同时运行 ROS 驱动、遥操作或其他占用同一设备的程序。

达妙电机反馈状态 `0x00` 表示失能、`0x01` 表示正常使能，两者都不视为故障。状态读取和启动反馈检查使用同一判断，真实故障或缺失反馈会报告具体电机及状态码。界面使能状态仍表示当前控制器已完成使能流程，不会仅凭外部电机上电自动授权运动。

停止任务会中断后续步骤并请求保持，不默认失能或张开夹爪。显式失能会释放力矩；界面提供一次提示。真机使能时，正常服务退出会拒绝直接断开，先停止任务、支撑机械臂并显式失能。关闭网页不等于关闭后台服务，运行任务在网页心跳丢失后请求停止。进程被强杀、电脑休眠或 USB 拔出时，软件无法保证保持。

## 范围与限制

- 当前碰撞检查只覆盖已加载机械臂模型的自碰撞；没有环境桌面、外部障碍物、持物几何或动态障碍检测。它不等价于原 MoveIt 场景校验。
- 沿关节路径按最大 `0.02 rad` 间隔检查，夹爪开口变化采样检查；不是连续碰撞保证。
- 第一版没有自动绕障、笛卡尔直线动作、视觉抓取、暂停续跑、多设备或远程访问。
- 程序最多展开 2000 步，循环最多 100 次，嵌套最多 8 层，总预算 30 分钟；运行使用提交时的固定程序及示教点快照；程序内新增示教点从实际反馈记录。
- 真机反馈、停止保持和 Windows 调度性能尚需现场验证，不能把模拟测试视为实机验收。
- 使用来源项目、SDK 和模型的许可约束；Blockly 本身的 Apache-2.0 授权不会改变这些组件的许可。

## 数据与本机接口

服务只监听 `127.0.0.1`，固定同源接口不接受任意 ROS 路径、脚本或外部后端地址。浏览器不执行导入的 Python/JavaScript。项目名通过摘要映射为文件名，项目写入使用临时文件替换。

Windows 数据目录为 `%LOCALAPPDATA%\ZekeeparmStudio`，Linux 为 `~/.local/share/ZekeeparmStudio`。用 `--data-dir` 指定其他目录，`--port` 指定端口，`--no-browser` 禁止自动打开浏览器。草稿保存在当前浏览器和端口的本地存储中，正式迁移请导出 JSON。

主要接口：`GET /api/config`、`GET /api/state`、`POST /api/connect`、`/api/enable`、`/api/run`、`/api/stop`、`/api/check`、`/api/fk`、`/api/ik`、`/api/heartbeat`。写接口要求 `Content-Type: application/json` 和 `X-Studio-Request: 1`，仅供本机前端调用。

## 验证

可使用 `python package_windows.py <输出ZIP路径>` 导出裁剪后的独立 Windows 源码包，包含根目录启动入口和使用说明。压缩包不包含 Conda/Python 运行时；Windows 首次使用需联网安装依赖。

```bash
python -m unittest discover -s tests -v
npx playwright install chromium
npm run test:e2e
```

Playwright 测试在独立端口启动服务，覆盖界面初始化、模型加载、程序检查、模拟设备、示教点、文件保存导出、项目恢复、IK、运行取消、预览以及 320/768/1024/1440 px 布局。测试不连接硬件。
